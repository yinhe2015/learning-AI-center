Codex 网页工作台 · 第一版需求

目标
在 macOS 上运行一个多用户网页工作台，复用宿主 Mac 已安装、已登录的 Codex。用户在自己的项目中与 Codex 对话、上传资料，并预览生成的网站。

账户与项目
- 网页支持自助注册、登录和退出。每个账户有独立的持久化工作目录，可以创建多个项目。每个项目有自己的目录、附件和会话。
- 普通用户只能通过网页访问自己账户下的资源。后端按资源归属授权，Codex 命令和项目预览进程使用项目文件系统沙盒。
- 所有网页账户共用宿主 Mac 上的 Codex 登录和模型用量。网页账户用于分隔工作台里的项目和会话。

对话与附件
- 用户在选定项目中创建会话，发送消息并实时查看 Codex 输出，也可以重新打开已有会话继续对话。
- 模型的普通问句在消息中显示。执行期间的结构化问题显示为答题卡，回答须回传给提出问题的原运行。浏览器刷新后，仍待回答的问题应重新显示。
- 用户可向项目上传文档、图片等资料，也可把资料随消息发送。文档保留原文件，Codex 通过项目相对路径读取。PNG、JPEG、WebP 图片可在网页预览，并可作为视觉输入传给 Codex。

本机访问与局域网访问
- 工作台可在宿主 Mac 使用。开启局域网模式后，同一网络的设备可通过 HTTPS 访问工作台。
- 用户可启动、打开和停止项目预览，支持静态网站和项目的前台 Web 服务。预览在 Codex 对话结束后仍运行，停止预览或关闭工作台时结束。
- 在局域网模式下，每个运行中的项目预览获得独立的 HTTPS 端口。远程设备使用工作台提供的完整链接，通过 Mac 的局域网地址或已配置的域名打开所属项目。

数据与验收
- 数据默认写入本仓库的 .workbench-data/，包括账户与会话数据库、项目文件、上传资料、Codex 运行数据和局域网证书。重启后应可继续打开原项目和会话。
- 使用两个普通账户验证跨账户项目、附件、会话和预览入口的访问限制。
- 验证真实 Codex 对话支持流式输出、结构化提问回传、项目文档读取和图片识别。
- 同时启动两个项目预览，确认端口彼此独立，远程设备能打开预览，停止后对应端口会关闭。
